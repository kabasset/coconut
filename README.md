# Coconut

## Data processing organization CO2 footprint estimator

Coconut offers tools (CLI and Python API) to estimate the CO2 footprint of organizations aimed at processing data.
It covers:

* Human resources, including:
  * personal computer equipment,
  * home-to-work travels,
  * business travels;
* Shared hardware, including:
  * storage,
  * processing units.
